# Hano 0.1.0b1

Initial beta of **Home Assistant Notification Orchestrator**, a native integration
for mobile notifications, immediate voice announcements, and persistent Home
Assistant notifications. Requires Home Assistant 2026.10 or newer.

## Included

- Native graphical `hano.send`, `hano.preview`, and `hano.resolve` actions.
- Per-person presence and sleep routing, optional waiting, and nearest-person
  selection without `proximity` entities.
- Persistent logical notification IDs and cycles, content updates without voice
  replay, expiration, and synchronized resolution on supported channels.
- Configurable buttons with Home Assistant action sequences, resolution after
  success, or URI links; correlated events and stale/duplicate callback protection.
- Companion capability checks, basic `notify` entities, TTS to explicit speakers
  or occupied rooms, and opt-in Sonos native announcement volume.
- An administrator-only Lit panel, English/French/Spanish interfaces, editable
  people and rooms, preview and real-test controls, revision-protected drafts,
  history retention, and redacted diagnostics.
- Python and frontend tests, a fictional standalone demonstration, documented
  migration, and CI/release gates for Hassfest and HACS validation.

## Install the beta

Add `https://github.com/Gnol86/Hano` as an **Integration** custom repository in HACS,
enable prerelease/beta visibility, and select `0.1.0b1`. Restart Home Assistant,
then add **Hano** in **Settings → Devices & services**. Hano has not been submitted
to the default HACS catalogue.

## Limits and migration

An accepted downstream action is not proof of device delivery, reading, or hearing.
Remote clearing and receipt events depend on Companion and the mobile OS. Generic
`notify` destinations cannot be remotely cleared; unsupported rich options are
rejected explicitly. Voice is immediate only and is not replayed after a restart.
Per-announcement volume is limited to verified Sonos players.

This is a beta for deliberate validation before replacing existing workflows.
There is no automatic household installation, automation conversion, or Notifier
shutdown. Follow the [migration guide](https://github.com/Gnol86/Hano/blob/v0.1.0b1/docs/migration.md) to prepare a separate,
reversible cutover. Publishing this release does not establish device behavior in
an actual household.
