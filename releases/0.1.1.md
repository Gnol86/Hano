# Hano 0.1.1

Fix Companion mobile-device discovery for Home Assistant's current device registry.
Requires Home Assistant 2026.10 or newer.

- Replace the deprecated device lookup with `async_get_device_by_identifier()`,
  scoped to the Companion registration that owns the device. This removes Hano's
  warning about the old API being removed in Home Assistant 2027.8.
- When registrations share a device identifier, select the device belonging to
  the correct registration. Skip registrations whose own device is missing.
- Add regression coverage for both cases. Existing configuration, notification
  cycles, and storage format are preserved.

Update to **0.1.1** through HACS and restart Home Assistant to load the fix.
No changes to automations or notification settings are required.
