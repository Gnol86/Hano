# Hano 0.3.0

Expose active notifications to Home Assistant dashboards through one optional
sensor. Requires Home Assistant 2026.10 or newer.

- Enable **Active notifications sensor** in **Tests & settings → Dashboard**.
  The option is off by default, including for existing installations.
- `sensor.hano_active_notifications` counts active notification cycles and lists
  their display content in its `notifications` attribute, newest first. Pending
  deliveries remain included; resolved, expired and replaced cycles are removed.
- Updates apply after successful persistence, including content changes at an
  unchanged count. The sensor restores from Hano's stored cycles after a restart.
  Disabling it keeps its identity, makes it unavailable and clears the list without
  resolving notifications. No per-notification option or automation change is needed.
- The export is global: users who can read the entity can read its notification
  content regardless of recipients. Destinations, button actions, tokens and
  history are excluded. The notification list is not stored in Recorder history.
- Add English, French and Spanish settings and entity names, plus a native
  Markdown dashboard example in the README.

Update to **0.3.0** through HACS and restart Home Assistant. Enable the sensor only
if you want to share active notification content through a dashboard entity.
Existing sends, reminders, resolution rules and stored cycles remain compatible.

Validation: 331 Python tests, 44 frontend tests, Ruff, TypeScript and a reproducible
panel build under Node 24. No physical notifications were sent during validation.
