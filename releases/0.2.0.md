# Hano 0.2.0

Choose an imported iOS notification sound and optionally repeat mobile
notifications until someone explicitly acknowledges them. Both features are
configured per action and preserve existing behavior when omitted.
Requires Home Assistant 2026.10 or newer.

- Add `ios_sound` to send and preview actions and the test panel. Critical alerts
  use the named sound with `critical: 1` and `volume: 1.0`; normal and important
  alerts use the filename. Import the file into Companion on each selected
  iPhone first. Sounds must last less than 30 seconds. Quiet priority, Android,
  generic notify destinations and requests without the mobile channel reject
  this option before sending.
- Add optional `reminder_interval` (60–86400 seconds) and `reminder_limit`
  (1–100 additional attempts per destination). Both default to zero, disabled.
  Reminders require an explicit resolution-only acknowledgement button.
  One person's acknowledgement resolves the cycle for everyone. Technical
  receipt, display, opening and reading are not interchangeable.
- Recheck presence and sleep before each reminder, preserve each destination's
  budget across updates and restarts, and never catch up missed intervals at
  startup. Resolution, expiration and a replacement cycle stop reminders.
  Failed or uncertain calls are not retried automatically. Voice and persistent
  HA cards are not replayed by reminders.
- Preserve acknowledgement buttons across reminders of unchanged content while
  retaining protection against buttons from older updates or replaced cycles.
- Add English, French and Spanish forms, per-destination reminder progress, and
  documentation for sound import, acknowledgement and update behavior.

Update to **0.2.0** through HACS and restart Home Assistant. Existing automations,
recipient configuration and stored cycles remain compatible. Updating does not
import sound files onto phones or enable reminders in existing automations.

Validation: 285 Python tests, 41 frontend tests, Ruff, TypeScript and a reproducible
panel build. Software checks do not establish actual playback on a phone.
